# Repository Rules for Vaultonaut

## Git & Commit Directives
- When committing changes to Git and pushing to GitHub:
  - Do NOT write detailed commit descriptions, bodies, or update README files with change summaries.
  - Use short, simple commit messages (e.g. `git commit -m "Update vaultonaut"`).
  - Just add the files (`git add .`), commit simply, push to the repository, and leave it.
